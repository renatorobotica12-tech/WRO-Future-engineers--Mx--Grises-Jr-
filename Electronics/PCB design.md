# PCB Design

This directory contains the hardware design files for the custom PCB used in the project.

The board is designed around an Arduino Nano and provides:
- Power input through a screw terminal.
- Regulated power distribution to multiple JST connectors.
- Dedicated input and output connectors for external peripherals.
- Optional I2C expansion header (EV3 compatible footprint).
- Enable (EN) control pads.
- Mounting holes for secure installation.
- Clearly labeled silkscreen for simplified assembly and debugging.

This PCB serves as the main interface board, simplifying wiring and providing a compact, reliable platform for connecting sensors, actuators, and expansion modules.
